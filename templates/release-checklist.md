## 公開前

- [ ] package、lockfile、実行コードの版が一致する。
- [ ] 公開entryとbundle patchがGitHub取得物・tarballに入っている。
- [ ] 同梱asset・font・licenseを確認した。
- [ ] 固定依存からbuildし、追跡する生成物との一致を確認した。
- [ ] 関連する型検査・テストを実行した。
- [ ] 隔離したDSH profileで新規導入・無効化・削除を確認した。
- [ ] 旧版から更新し、設定・資格情報・ON/OFFを確認した。
- [ ] 新しいClient entry・設定欄を追加した場合、旧版を起動したままの更新とHost再起動後の登録を確認した。
- [ ] 導入版と実行版を分け、Web版のサーバー再起動とブラウザー再読み込みの手順を記載した。
- [ ] 生成物の`dist/`と配布物の`release/`を分けた。
- [ ] 公開assetを名前で指定し、checksumを照合した。
- [ ] 再起動、migration、復旧の条件をRelease本文に書いた。

## 公開後

- [ ] 公開tagと対象commitが一致する。
- [ ] Release asset一覧が意図したfileだけである。
- [ ] 公開URLから取得したtarballのchecksumが一致する。
- [ ] 公開済みの導入指定・tarballからDSHへ入れて起動を確認した。
- [ ] 再起動後の実行版を確認した。
- [ ] 新しい設定欄と対象機能を確認した。標準詳細の版・Running表示だけを反映済みの根拠にしていない。

共存の確認は、対象pluginすべての版と操作を記録します。前の組み合わせの成功を、新しいモバイル表示・theme変更の成功へ転記しません。

## 未検証・既知の制約

今回の配布に関係する未確認のOS・API・layout・互換性を記載します。

## 復旧

戻す版と導入指定、保存データを戻せる範囲、必要なbackupを記載します。資格情報の値やbackupの内容は公開しません。
